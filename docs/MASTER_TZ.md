## 10. Протокол «Экранный дескриптор»

Формат (имена полей английские — стабильность парсинга; значения — как на экране):

```json
{
  "active_window": "Блокнот",
  "screen_size": [1920, 1080],
  "elements": [
    {"type": "button", "text": "Отправить", "bbox": [412, 580, 488, 612], "confidence": 0.93},
    {"type": "input", "text": "Поиск...", "bbox": [20, 8, 300, 36], "confidence": 0.88}
  ],
  "summary": "Диалог отправки письма, фокус в поле поиска"
}
```

- type: button | input | link | menu | text | icon | image; bbox: [x1, y1, x2, y2];
  confidence: 0–1.

### 10.1. Грамматика: JSON по принуждению (совет Создателя №1)

Промпт «выдай строго JSON» — просьба; грамматика — закон. Основной путь — per-request
`response_format` в теле каждого запроса:

```json
"response_format": {"type": "json_schema",
                    "json_schema": {"name": "screen_descriptor", "schema": {...}}}
```

- llama-server сам строит GBNF из схемы — модель физически не может сгенерировать
  токен вне JSON: ни ```-заборы, ни «Вот JSON:».
- Схема — только каркас (required: elements; bbox из 4 целых), без лишних ограничений,
  чтобы не душить качество 3B.
- Работает без перезапуска сервера; глазам будут задаваться и короткие да/нет-вопросы
  с другими схемами. Если сборка не знает поле — оно игнорируется, работает
  парсер-фолбэк (срез ```-заборов); скрипт печатает, принят ли response_format.
- Тяжёлая альтернатива — `--grammar`/`--json-schema` при старте сервера: жёстко, но
  для ВСЕХ запросов. Не основной путь; в Г-3 можно переехать, когда дескриптор станет
  единственным форматом выхода глаз.

### 10.2. Координаты и DPI-калибровка (совет Создателя №2)

Две независимые проблемы, обе закрыты:

1. **Пространство снимка ≠ физический экран.** Снимок масштабируется до 1600 px;
   координаты VLM — в пространстве снимка. Исполнитель умножает на коэффициент
   (физическая_ширина / 1600); скрипт печатает коэффициенты по обеим осям.
2. **DPI-виртуализация Windows (125%/150%).** Не-aware процесс получает от мыши
   логические координаты — pyautogui жмёт мимо даже при верном коэффициенте. Решение:
   `SetProcessDpiAwareness(2)` (per-monitor aware) на старте каждого процесса-сенсора —
   тогда mss и pyautogui говорят в физических пикселях. Зашито в vision_smoke.py v1.1;
   в Г-3 переезжает в calibrate.py.

Тест «Пуск» (встроен в smoke): свежий снимок → сфокусированный вопрос «найди кнопку
Пуск, верни bbox» → центр bbox пересчитывается в физические координаты →
`pyautogui.moveTo` (failsafe=True, 0.6 с) → Илья визуально подтверждает. С флагом
`--click-start` — полный замкнутый цикл: клик → новый снимок → «открыто ли меню?» →
Esc. Клик только по валидированному центру bbox; мышь в угол = аварийный стоп (FAILSAFE).

### 10.3. Как мозг получает дескриптор

- В системный промпт 30B — блок «ЭКРАН (снимок N сек назад): {дескриптор}».
- Элементы с confidence < 0.6 мозг обязан считать НЕИЗВЕСТНЫМИ.
- Дескриптор не вытесняет ЯДРО системного промпта (№51/№60).

### 10.4. Правила честных глаз (анти-галлюцинации)

1. temp 0.1, top_p 0.8, top_k 20 — сенсор почти детерминирован.
2. Грамматика JSON (10.1) + запрет в промпте: «Не выдумывай элементы. Нечитаемое —
   confidence < 0.4. Лучше пустой список, чем выдуманная кнопка».
3. Замкнутый цикл: после каждого действия — новый снимок и подтверждение изменения
   состояния экрана. Не изменилось — стоп и вопрос Илье.
4. Глаза не интерпретируют намерения — только факты. Интерпретация — работа мозга.

Честные риски прогнозов:

- Q6_K ≥2× медленнее → остаёмся на Q4_K_M + заземление (сдвиг вехи терапии не критичен).
- Оба кванта врут → проблема в конвейере: аудит `brain.py`; v10 сдвигается на глубину аудита.
- VLM не влезает в VRAM (драйвер прожорливее) → mmproj Q4_K, ctx 4096 либо Qwen2-VL-2B.
- Pascal без тензорных ядер: ViT медленнее ожидаемого → ширина 1280 (площадь кадра 64%,

## 23. Словарь

- **Канон** — действующая сборка Марфы (v9.3) и её документы; меняется резолюцией Создателя.
- **ЯДРО** — неизменяемая часть системного промпта (личность, доктрина); не режется (№51).

- **Батарея** — стандартизированный измеритель качества (мозга — 15 вопросов; глаз — V01–V05).
- **Волны** — очереди бэклога: 0 (чистый код), 1 (после вердикта), 2 (стройка), холодильник.
- **Гейт** — запрет на функции, где больной мозг производит сохраняемую «истину».
- **Вторые берега** — внешняя копия дома: GitHub + git bundle.
- **mmproj** — мультимодальный проектор: визуальный кодировщик VLM отдельным GGUF-файлом.
