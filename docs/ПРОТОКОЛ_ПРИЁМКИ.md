# МАРФА — ПРОТОКОЛ ПРИЁМКИ ФИШЕК (Ф50, №30 роадмапа-30)

> Единый формат приёмки для каждого круга и каждой фишки — по образцу
> приёмки Г-1 (глаза): критерии ДО работы, факт ПОСЛЕ, решение Создателя.
> Заполняется архитектором в конце круга; «почти готово» = «не готово».
> Место в доме: `C:\Marfa\docs\ПРОТОКОЛ_ПРИЁМКИ.md`
> Проверяется тестом: `tests/test_seal_circle.py` (структура — закон).

## Как заполнять (шаблон строки)

| Поле | Что вписывать |
|---|---|
| Круг / фишка | номер и имя («Ф41 память ответов») |
| Критерий | измеримое условие приёмки, ДО начала работы |
| Порог | число/состояние, при котором принимаем |
| Факт | что вышло по замеру (цифры или ничего) |
| Решение | ✅ принят / ✅ принят с отклонением / ✗ доработать — ставит Создатель |
| Уроки | что дом усвоил, чего не знал до фишки |
