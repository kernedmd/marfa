   RAM или VRAM — а их у дома 64 ГБ и 6 ГБ. Зоопарк не нанимается
   всем составом: берём по одному, когда доходит дело по карте.
2. **Мозг дома не меняется** — Qwen3-30B-A3B-Q4_K_M, вердикт батареи
   21.11 (гейт §5). Остальные текстовые модели — кандидаты, не замена.
3. **Найм модели = фишка по карте**: зелёный тест + коммит. Никаких
   «скачал — включил».
4. Суммарный вес арсенала — порядка сотни гигабайт: диск тоже ресурс,
   но правило дома «ничего не удаляется насовсем» — арсенал храним.
