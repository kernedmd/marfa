один токен, обнуляет кэш ЦЕЛИКОМ. Мозг пересчитывал все ~7400 ток

## Сессия «день-12» — ПУСТОЙ ОТВЕТ (24.11, вечер, круг 14, Ф81–Ф84)

   был словом-ярлыком на класс разных болезней.

Разбор: анти-эхо переспрашивало с общим уколом «ответь по
существу» — тот же класс лечения для разных хворей, и вторая
попытка честно повторяла первую. Журнал писал note=«пустой ответ»,
answer=null — улики ноль. Диагноз по классу требует улики, улика
требует сырья, сырьё уже ездило в ответе сервера — его просто
никто не сохранял.

Лечение — круг 14 «Пустой ответ». Ф81: журнал несёт raw при
«пустом ответе»/«не-json» (срез 600, только по поводу — честные
ходы сырой копией не раздуваются), BrainClient.last_raw — улика
агенту, честный сбой показывает её в чате. Ф82: закон ключа в
преамбуле ask_json («answer» латиницей, значение непустое) +
укол-диагност читает улику и называет модель КОНКРЕТНУЮ ошибку:
русский ключ / null / пустая строка — плюс формат одним хвостом.
Ф83: переводчик ключа — валидный JSON с ответом под чужим ключом
(«ответ», «response», «reply», «text») читается, ход не роняется,
вторая генерация не платится; ADR-002 цел (JSON валиден, регулярок
нет, выдумки нет — прочитано ТО, что мозг сказал); неизвестные
ключи и действия — мимо. Ф84: прогрев — старт дома после /health
в фоне платит префилл статичного префикса тем же путём ask_json

порты не греет) — первый вопрос Создателя едет по тёплым рельсам.

**УРОКИ ДНЯ.**
1. ПУСТОЙ ОТВЕТ — КЛАСС, А НЕ СИМПТОМ. Null, пустая строка,
   чужой ключ, думание мимо поля — разные болезни с одним
   ярлыком. Лечение без диагноза бьёт наугад: общий укол
   «ответь по существу» не отличает «модель молчала» от «модель
   ответила, но дом не прочитал». Правило: прежде чем лечить
   пустоту — спроси у неё, КАКАЯ она.
2. ЖУРНАЛ БЕЗ УЛИКИ — ТЕЛЕПАТИЯ. «21 ток и пусто» — вопрос
   Создателя «что она сгенерировала?» упирался в слово-ярлык.
   Улика уже ездила в ответе сервера — её просто не сохраняли.
   Правило: любое «не знаю, что было» в журнале — это дыра в
   журнале, а не в мире.
3. СПАСЕНИЕ ЧУЖОГО КЛЮЧА — НЕ ВЫДУМАННЫЙ ОТВЕТ. Модель сказала
   «проверка» под ключом «ответ» — дом обязан ПРОЧИТАТЬ, а не
   делать вид, что слов не было. Граница честности: читать можно
   только ДОГОВОРЁННЫЕ алиасы; угадывать по смыслу («а может,
   «мысль» — это ответ?») — уже телепатия.
4. ХОЛОДНЫЙ КЭШ ПЛАТИТ СТАРТ, А НЕ СОЗДАТЕЛЬ. Первый ход дня
   стоил 91 с не потому, что мозг медленный, а потому что его
   никто не прогрел. Всё, что дом может сделать до прихода
   Создателя, дом обязан сделать до прихода Создателя.
5. ЛЕЧЕНИЕ КЛАССА СТРОИТСЯ ИЗ УЛИКИ, А НЕ ИЗ ПЕРЕЧНЯ. Не «добавим
   ещё три ретрая», а цепочка: улика → диагноз → точный укол →
   узкое спасение → честный сбой с уликой. Каждый слой знает
   больше предыдущего и включается только тогда, когда предыдущий
