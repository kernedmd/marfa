## Как берём (доктрина дома, не обсуждается)

- **По одной.** Фишка = зелёный тест + отдельный коммит. Батчи запрещены:
  нетестируемая гора файлов — это не дом, это склад.
- Илья говорит «берём №N» — архитектор готовит файлы, рука Создателя
  раскладывает, тестит, коммитит.
- **S** = один файл + тесты (час). **M** = 2-3 файла, затрагивает агент
  или панель (вечер). **L** = трогает память/мозг глубоко (выходной).
- Порядок внутри групп — по номеру; между группами — как скажет Создатель.

## Самопознание (22.11.2026) — Г-2.3: Марфа знает о себе правду

Переписка Создателя с живой Марфой вскрыла слепоту одним разговором:
«изучи себя» → «мозг недоступен: timed out», потом трижды
«неизвестный инструмент: filesystem», а «ЧТО ты умеешь?» — общие
слова. Три корня, одно лечение (`core/identity.py` — зеркало дома):

- **манифест возможностей** — статичный блок системного промпта сразу
  после ЯДРА (префиксный KV-кэш цел): мозг видит ТОЧНЫЕ имена
  инструментов (`TOOLS` — единая истина: промпт и сверка исполнения
  читают один список) и быстрые команды; при неизвестном имени мозг
  получает меню настоящих — выдумывать «filesystem» неоткуда;
- **«изучи себя»** — быстрая команда (варианты: «кто ты», «что ты
  умеешь», «расскажи о себе», «твои возможности»): динамический
  честный отчёт без LLM — тело, живость глаз/ушей на сейчас, число
  живых записей памяти (`Memory.count()`), команды, инструменты и
  «чего не умею» без прикрас;
- **ЯДРО — правда о теле**: уши vosk живут (не «впереди»), голоса
  нет; уши появились и в состоянии дома для мозга — живость по
  сердцебиению `data\ears_status.json` (три пропущенных сердца =
  «не слышу»);
- **таймаут мозга — закон дома**: 120 с → 300 с
  (`BRAIN_TIMEOUT_SEC`): 768 токенов при ~6 ток/с — уже 128 с,
  старый обрыв был ложью для Pascal; при timed out Марфа объясняет
  человеческим языком: не поломка, спроси покороче.

Главный урок: мозг, не знающий имён своих инструментов, — не мудрец,
а фантазёр. Истина об именах едет в промпте из одного места в коде.
