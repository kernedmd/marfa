## 8. Как читать эту книгу

- Строка закрыта = зелёный тест + отдельный коммит; «почти готово»
  в этом доме означает «не готово».
- Сводные цифры §1 сверяются прогоном тестов (`scripts\run_tests.bat`,
  полный протокол — `logs\tests_last.txt`); на 24.11 день-13, утро
  полная батарея песочницы архитектора — **1517+2** (за 131 с;
  протоколы дня-9 с автопесочницей conftest: каждый тест живёт в своём data/).
- Источник правды по урокам — `docs/ARCHITECT_LOG.md`; по фишкам —
  `docs/ROADMAP_30.md`, `docs/ПРОТОКОЛ_ПРИЁМКИ.md` (Ф41–Ф55 с
  решением Создателя) и `CHANGELOG.md` (логбук v1.1 — книга не
  протекает: корень резолвится от кода, тесты пишут только в песочницу);
  по моделям — `docs/АРСЕНАЛ_МОДЕЛЕЙ.md`.
- Следующая ревизия этой книги — после живого Стоп→Старт на машине
  Создателя (проба KV-префикса решит сама), первых штампов «сек · ток»
  без мышления и живой пробы смысловой памяти: кнопка 93 →
  «переиндексируй смыслы» → «вспомни по смыслу <о чём>». Голосовой
  мост по-прежнему ждёт живой пробы «Марфа, который час» вслух.
