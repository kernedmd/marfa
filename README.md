# МАРФА — «Эволюция через знания»

Локальный автономный агент для HP Z440 (Xeon E5-1680 v3, 64 ГБ RAM, GTX 1060 6 ГБ, Windows 10/11).
Дом агента: `C:\Marfa` — всё живёт только внутри этой папки.

Master-ТЗ: [docs/MASTER_TZ_v9_3.md](docs/MASTER_TZ_v9_3.md) (v9.3 от 12.11.2026).

## Философия

Мы не трогаем веса 30B. Мы эволюционируем СРЕДУ:

1. ЧИТАЕТ интернет (Библиотекарь) → 2. ЗАПИСЫВАЕТ знания в память (RAG) →
3. АНАЛИЗИРУЕТ ошибки (Эволюционер) → 4. МЕНЯЕТ ХАРАКТЕР (промпт, геном).

**Развитие ≠ изменение весов. Развитие = память + промпт + руки.**

## Архитектура (ТЗ Раздел 2)

```
[Илья] → [core/agent.py] → [30B Qwen3-30B-A3B MoE на CPU, порт 8082]
  ├──→ [core/hands.py]      (руки: чистый Python)
  ├──→ [core/memory.py]     (память: ChromaDB + JSON-фоллбэк)
  └──→ [core/librarian.py]  (интернет, раз в час)
```

- Мозг: Qwen3-30B-A3B (MoE, 3.3B активных) — только CPU, `--mlock`, контекст 4096.
- GPU — только для QLoRA ночью (04:30–06:30), студент Qwen2.5-3B-Instruct.
- СТРАЖ (safety/guard.py) — один фильтр уровней LOW/MEDIUM/HIGH/CRITICAL/BANNED.
- RAM-бюджет: план 44 ГБ из 64 (аудит: docs/RAM_AUDIT.md), монитор Ф97: 85% тревога / 92% критично.

## Дисциплина (ТЗ Раздел 6)

1. Не внедрять фишку без теста. 2. Не коммитить без работающего кода.
3. Не менять Доктрину без Ильи. 4. Не трогать порт 5000.
5. Не превышать RAM-бюджет (44 из 64 ГБ) и VRAM (6 ГБ).
6. Логи — единственный источник правды. 7. Откат через `git revert`, а не «починю потом».

Каждая фишка — отдельный коммит. GitHub — приватный репозиторий
`github.com/kernedmd/marfa`, ветка `main`, обновления только через GitHub (правило 0.2).

## Запуск тестов (офлайн, без 30B)

```bat
python -m pytest tests/ -v
```

Все тесты офлайн: мозг подменяется мок-сервером, память — JSON-фоллбэком (ADR-006).
Установка на чистую Z440: см. [README_УСТАНОВКА.md](README_УСТАНОВКА.md) и `scripts\00_install_all.bat`.
