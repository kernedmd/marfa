## 8. Как читать эту книгу

- Строка закрыта = зелёный тест + отдельный коммит; «почти готово»
  в этом доме означает «не готово».
- Сводные цифры §1 сверяются прогоном тестов (`scripts\run_tests.bat`,
  полный протокол — `logs\tests_last.txt`); на 23.11 утро полная
  батарея песочницы архитектора — **1106+2** (flask на месте; 3
  сна-оконных теста зелёные вне окна 01:30–07:00 UTC — в окне падают
  по устройству сна, не регрессия).
- Источник правды по урокам — `docs/ARCHITECT_LOG.md`; по фишкам —
  `docs/ROADMAP_30.md` и `CHANGELOG.md` (логбук v1.1 — книга не
  протекает: корень резолвится от кода, тесты пишут только в песочницу);
  по моделям — `docs/АРСЕНАЛ_МОДЕЛЕЙ.md`.
- Следующая ревизия этой книги — после рестарта мозга (терапия §15
  ждёт Стоп → Старт) и первых живых замеров «сек · ток» из чата;
  голосовой мост ждёт живой пробы «Марфа, который час» вслух.
