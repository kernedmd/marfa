## 1. Доктрина органа

| | Первый рот (горло) | Запасной рот (SAPI) |
|---|---|---|
| Модель | Silero v5_6_ru (torch.package, ~147 МБ) | System.Speech (Ирина) |
| Где живёт | CPU, 4 потока, ~0,5–1 ГБ RAM, порт 8084 | PowerShell-процесс на лету |
| Интонация | живая: «?» и «!» читает сам + SSML prosody | rate −5..5, механическая |
| Голоса | бая, ксения, ксения-латинская, айдар, евгений | что установлено в Windows |
| VRAM | 0 (глаза не трогаем — принцип хозяина ресурса) | 0 |
| Когда говорит | слуга разбужен (кнопка 95 / «проверь голос») | всегда — запасной путь |

**Глотка отделена от рта.** Слуга СИНТЕЗИРУЕТ и отдаёт WAV-байты по
HTTP; воспроизведение (рот) остаётся в теле дома — winsound (stdlib
Windows) играет байты в потоке-демоне. Слуга не трогает колонки, как
эмбеддер не занимается поиском. Следствие: орган кроссплатформенен —
torch.package не знает, где живёт, — и впервые в истории дома
проверяется ЖИВЬЁМ в песочнице архитектора (Ф123): песочница слышит
те же байты, что услышит станция.

**Цепь честна (Ф122): silero → SAPI → честный отказ.** Горло спит —
говорит SAPI (дом не молчит ни секунды). Горло подавилось — SAPI
подхватывает, исключение глотается (закон эфира). Оба молчат —
честный отказ с путём лечения. Один голос в один момент: MOUTH_LOCK
держит ОБА рта (закон Ф56 цел).

## 4. Органы круга (Ф121–Ф123)

- **Ф121 «СЛУГА-ГЛОТО»** — sensors/throat.py (слуга: torch.package,
  /health + /say → WAV-байты, однопоточный сервер — вторая фраза
  ждёт первой; закон ленивого torch: модуль импортируется без torch)
  + core/throat.py (клиент и чистая логика: спикеры, нормализация
  текста, prosody, чтение WAV-заголовка; ensure_server/lay_to_rest
  по образцу эмбеддера). Порт 8084 — наследие рук v1 (UI-TARS),
  свободен с 22.11.
- **Ф122 «ГОЛОСОВАЯ ЦЕПЬ v2»** — core/voice.py: горло — первый рот,
  SAPI — запасной; «голос <имя>» / «смени голос <на имя>» — смена
  голоса горла (настройка в data\voice_settings.json, переживает
  перезапуск); «какой голос» — цепь целиком; «какие голоса» — весь
  дом; «говори медленнее/быстрее» доезживает до обоих ртов (SAPI
  rate −5..5 ↔ silero prosody x-slow/slow/fast/x-fast); громкость —
  масштаб сэмплов в слуге; «проверь голос» — тест цепи (проба идёт
  через speak — путём пользователя); self-knowledge (identity.py)
  знает новый голос честно.
- **Ф123 «ЗОЛОТОЙ ЯКОРЬ ГОЛОСА»** — tests/test_throat_circle.py,
  21 якорь: 17 железных (спикеры, нормализация Ф23, prosody, SSML,
  WAV-заголовок, закон ленивого torch в чистом подпроцессе, цепь
  швами, броня настроек, маршруты ЧЕРЕЗ КАЛИТКУ agent.handle) +
  4 живых (модель та самая, фраза жива байтами, интонация «?»/«!»/«.»
  различается байтами, спикеры различаются байтами). Живые якоря —
  ПЕРВЫЕ в истории дома, что слушают орган, а не читают его код:
  орган кроссплатформенен, песочница = станция. Орган спит (нет
  torch/модели) — честный skip с путём лечения, не зелёная ложь.

## 5. Протокол слуги (localhost only)

```
GET  /health → {"ok":true,"sensor":"throat","model":"v5_6_ru.pt",
                "speakers":["baya","kseniya","xenia","aidar","eugene"],
                "threads":4,"sample_rate":48000,"synths":N}
POST /say    {"text":"…","speaker":"baya","rate":-5..5,"volume":0..100}
          → 200 audio/wav (X-Marfa-Duration, X-Marfa-RTF)
          → 400 {"error":"честная причина по-русски"}
```
Слуга сам делает: нормализацию (markdown-шум снят, целые числа —
прописью через Ф23; дроби/даты/«007» честно остаются цифрами),
SSML-темп (rate≠0), громкость (масштаб сэмплов). Клиент проверяет
RIFF-заголовок — пустышке от WAV-органа дом не рад (закон фактов).

## 6. Команды Создателя

| Команда | Что делает |
|---|---|
| «скажи вслух <текст>» | произносит: горло → SAPI → честный отказ |
| «говори вслух» / «молчи» | озвучка ответов (Ф57, без изменений) |
| «говори медленнее/быстрее/нормально» | темп ОБОИХ ртов (SAPI rate; silero prosody) |

| **«какой голос»** | цепь целиком: кто говорит, каким голосом |
| **«какие голоса»** | весь дом: горло + запасной рот |

| «прочитай вслух <экран/дневник/ответ/визитку>» | как прежде, но голосом горла |

## 7. Посылка USB (дом офлайн — единственный транспорт тяжёлого)

На ЛЮБОЙ онлайн-машине с Python (версия не важна — качаем под станцию):

```
pip download torch --index-url https://download.pytorch.org/whl/cpu ^
  --only-binary :all: --python-version 311 --platform win_amd64 ^
  -d usb\wheels
```

Модель (та самая, что слушал Создатель; sha256 — канон файла):

```
https://models.silero.ai/models/tts/ru/v5_6_ru.pt
147 664 410 байт
sha256 04cc9b1d08ce38bcaa9d02c488d80d3e6806d17f7eaa7c95982f36a3cbf50b2e
```

На флешке приехывают: папка `wheels\` (torch CPU + зависимости) и
`v5_6_ru.pt`. В доме:

1. `wheels\` → `C:\Marfa\incoming\wheels\`
2. `v5_6_ru.pt` → `C:\Marfa\models\voice\v5_6_ru.pt`
3. кнопка **scripts\95_Горло.bat → [4] установить посылку**
   (pip --no-index --find-links — интернет не нужен)
4. та же кнопка **[2] поднять слугу** → в чате **«проверь голос»** —
   услышишь новый голос Марфы (бая, восклицание живое)

Почему torch НЕ в requirements.txt: синк (кнопка 80, шаг 3) ставит
requirements при каждом приёме — pip офлайн упёрся бы в PyPI на
каждом круге. torch едет посылкой, как QLoRA-стек (04_install_qlora)
— прецедент дома. До посылки горло спит, цепь честно говорит SAPI,
батарея показывает 4 честных skip с этой причиной; после посылки —
все 1580+2 якоря зелёные, как в песочнице архитектора.

## 8. Что НЕ входит в v1 (честный scope)

- Дискретные эмоции — их нет в модели (type_str игнорируется);
  краски — пунктуация и prosody. Не обещать того, чего орган не умеет.
- Дроби, даты, телефоны прописью — работа смысла (мозга), не глотки;
  целые числа — пожалуйста (Ф23).
- SSML-pitch команды («выше тоном») — механика есть (prosody pitch),
  команды нет: сначала пусть Создатель послушает базу.
- Автоподъём слуги из «скажи вслух» — доктрина слуги по вызову.
- Мужской голос по умолчанию — айдар и евгений в домике, командой.
