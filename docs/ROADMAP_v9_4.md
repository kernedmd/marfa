## 4. Этап 1 — диагностика мозга

Метод — изоляция: сырой мозг (батарея напрямую в 8082, скрипт

Врёт сырой мозг → квант/сэмплинг/шаблон. Чист, а врёт Марфа → персона/RAG/обрезка.

| Гипотеза | Как проверить | Что чинить |
|---|---|---|
| Квант: Q4_K_M на MoE деградирует (факты, русский) | A/B: батарея на Q4_K_M и Q6_K | перейти на Q6_K (файл уже на диске) |
| Сэмплинг вне рекомендаций Qwen3 | сверить флаги llama-server; прогон с `--temp 0.7 --top-p 0.8` | задать параметры явно |
| Thinking-режим: обрывки тегов | батарея помечает обрывки; логи | поддержать `reasoning_content` либо отключить |
| Контекст 4096: хвост вытесняет SYSTEM | логи llama-server; длина промпта | `-c 8192`; аудит обрезки в brain.py |
| Персона/RAG без заземления | сравнить сырой мозг и конвейер | рамки «данные — не истина» |

Принести архитектору: bundle; командную строку llama-server и содержимое
`start_llama_server.bat`; первые ~50 строк лога после старта; JSON-логи прогонов.
