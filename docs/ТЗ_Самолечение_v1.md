# ТЗ_Самолечение_v1 — Марфа чинит себя сама

**Дата:** 22.11.2026, ночь. **Статус:** v1 доставлена (порт 8085,
конвейер патчей жив, 566 passed + 2 skipped).

## 0. Слово Создателя

«Что то мы сильно заморочились, надо идти дальше по строению дома, и
давать марфе самой себя лечить и доделывать, она достаточно умная
модель, многое может поднимать, разбирать и делать сама. К тому же
среди умных рук у неё есть очень прокачанная модель 7b, котоая хорошо
знает питон».

АРСЕНАЛ про qwen2.5-coder-7b-instruct писал: «Кодинг: дом пока не
программирует. Вернёмся, когда Марфа начнёт чинить свои кнопки сама».
День наступил.

## 1. Доктрина ролей (кто кого не трогает)

| Роль | Кто | Право |
|---|---|---|
| ДИАГНОСТ | Создатель или мозг-30B | ставит ТРЕБОВАНИЕ к файлу |
| КОДЕР | qwen2.5-coder-7b (слуга 8085) | печатает код ЦЕЛИКОМ, не рассуждает о доме |
| СТРАЖ | safety/guard + _check_patch | синтаксис, лимиты, канарейки, пути |
| СОЗДАТЕЛЬ | Илья | единственный, чья команда меняет код дома |

МОЗГ не чинит файлы сам, как не жмёт кнопки: он ДОВЕРЯЕТ требование
кодеру (инструмент `code_patch` — как `ui_action` рукам). КОДЕР не
знает устройства дома — он видит один файл и одно требование.

## 2. Конвейер (ПС-1 → ПС-2)

```
«почини <файл>: <что сделать>»
  │
  ├─ страж пути: файл внутри дома (guard.check_path)
  ├─ чтение файла (hands.read_file; новый файл — самый лёгкий случай)
  ├─ VRAM-танец: кодер ~4.7 + глаза 3.0 > 6 ГБ → глаза присели
  │  (та же механика _stop_llama, что у рук; вернуть их — доктор)
  ├─ КОДЕР: «верни исправленный файл целиком в ```python»
  ├─ СТРАЖ ПАТЧА: только .py · ≤250 строк · ast.parse · канарейки ·
  │  «вернул без изменений» = брак
  ├─ патч -> data\patches\000N\<имя файла> + meta.json   [ПЕСОЧНИЦА]
  ├─ кодер лёг, глаза вернулись
  ▼
Создатель смотрит патч (блокнот)
  │
  ├─ «примени патч N» -> бэкап старого -> hands.write_file (страж)
  │                      meta.applied = True   [ПС-2, воля Создателя]
  └─ «откати патч N»  -> бэкап возвращается
```

**Неприкосновенность (главный закон):** `make_patch` НИКОГДА не пишет
вне `data\patches\`. Код дома меняет только команда Создателя
(«примени патч N»), с бэкапом и откатом. Это воздушный шлюз моторики
(кнопка 91), только для кода.

## 3. VRAM-арифметика

Кодер 7B Q4 ≈ 4.7 ГБ + глаза 3.0 ГБ > 6 ГБ (GTX 1060) — вместе не
живут. Тот же танец, что у рук: глаза присели → кодер поднялся →
написал → лёг → глаза вернулись лечением доктора. Кодер и руки (5.4)
вместе тоже не живут — ремонт и моторные задачи не пересекаются в v1
(если случится — второй просто честно откажется подняться).

## 4. Страж патча (что проверяется)

1. путь — внутри дома (страж пути, как read_file/write_file);
2. только `.py` — v1 не чинит батники и конфиги;
3. ≤ 250 строк — предел честности 7B: длинные файлы «плывут»;
4. `ast.parse` — синтаксис это истина, не мнение модели;
5. канарейки и секреты (guard.check_secrets);
6. «вернул без изменений» — брак: требование не выполнено.

Применение перепроверяет синтаксис ещё раз — между написанием и
применением файл патча могли тронуть руками.

## 5. Уровни (как Круги Р у рук)

- **ПС-0** слуга поднимается и отвечает на промпт — без записи файлов;
- **ПС-1** `make_patch` — патч в песочницу (ДОСТАВЛЕНО);
- **ПС-2** `apply_patch`/`rollback_patch` — по команде Создателя,
  с бэкапом (ДОСТАВЛЕНО);
- **ПС-3** (впереди) «доклад о хворях»: Марфа сама читает журнал
  уроков (evolution) и ПРЕДЛАГАЕТ патчи повторяющимся болям;
- **ПС-4** (впереди) диффы вместо целых файлов, автозапуск тестов
  после применения, кириллица в печать рук.

## 6. Команды и инструменты

| Что | Кто говорит | Что происходит |
|---|---|---|
| «почини <файл>: <что сделать>» | Создатель | ПС-1, патч в песочнице |
| «патчи» | Создатель | список с статусами |
| «примени патч N» | Создатель | ПС-2, бэкап + запись |
| «откати патч N» | Создатель | возврат бэкапа |
| `code_patch {path, requirement}` | мозг | тот же ПС-1 |

Лог: `logs\repair_log.jsonl` (правило 6.6). Брак и ошибки — в уроки
эволюционера (`кодер-брак`, `кодер-ошибка`).

## 7. Честные границы v1

- файлы только до 250 строк — большие архитектору;
- нет диффов: кодер возвращает файл целиком (диффы — ПС-4);
- тесты после применения гоняет Создатель кнопкой тестов — кодер сам
  их не запускает (v2: автозапуск в песочнице);
- модель ищется в чулане по шаблону `*coder*7b*.gguf` — точное имя
  файла могло измениться, нет модели — честный отказ.

## 8. Урок для эволюционера

Мозг-30B медленный, но мудрый (диагноз и требование); кодер-7B быстрый,
но узкий (печатает код). Дом нанял их НА РАЗНЫЕ РАБОТЫ, как нанял
глаза отдельно от рук: специализация слуг — закон дома с Г-1.
