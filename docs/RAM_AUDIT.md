# Аудит RAM дома Марфа (ТЗ 0.1)

Железо: HP Z440, Xeon E5-1680 v3 (8C/16T), **64 ГБ RAM**, GTX 1060 6 ГБ (VRAM не считаем здесь — она только для QLoRA).

План потребления при `--mlock` (правило 0.5):

| Статья | ГБ | Комментарий |
|---|---:|---|
| 30B Q4_K_M — веса | 19.0 | файл 18.63 ГБ, при mlock резервируется целиком |
| KV-кэш при контексте 4096 | 2.0 | правило 0.3: контекст больше нельзя |
| Windows + Python + агент | 5.0 | служебное |
| QLoRA ночью (студент + буферы) | 8.0 | 30B не выгружается — окно 04:30-06:30 |
| Запас (браузер Ильи, бэкапы, распаковка) | 10.0 |  |
| **ИТОГО план** | **44.0** | из 64 → **резерв 20 ГБ** |

Контроль:
- Константы: `core/config.py` (`RAM_TOTAL_GB`, `RAM_BUDGET_GB`, `RAM_PLAN_GB`, `MODEL_QUANTS_GB`).
- Монитор Ф97: `sensors/monitor.py` — тревога на 85%, критично на 92% **от фактического объёма** (не от плана).
- Тест `tests/test_config.py::test_ram_budget`: план сходится в 44 ГБ, 44 < 64.

Q6_K (25.10 ГБ): RAM хватает с `--mlock` — веса 25.1 + KV 2 + служебное 5 + резерв 10 = 42.1 < 64,
но ночью QLoRA при Q6_K оставляет меньше запаса (42.1 + 8 = 50.1, резерв сжимается до 13.9 ГБ —
в рамках, но решение о смене кванта принимает Илья по недельным логам — Раздел 8 ТЗ).
